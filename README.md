# CartMuse

Independent editorial fashion discovery website built with Next.js 16, React 19 and Tailwind CSS 4.

## Start

Run npm ci and npm run dev. For checks, run npm run lint and npm run build.

## Environment

Copy .env.example to .env.local. Set NEXT_PUBLIC_SITE_URL to your production domain. Set NEXT_PUBLIC_SHEIN_AFFILIATE_URL only after you obtain an approved, valid link from the SHEIN affiliate dashboard. Otherwise outbound links go to the official SHEIN homepage without affiliate tracking.

## Features

Editorial storefront, responsive discovery filters, local saved looks, guided deal finder, educational shopping guides, ZAR savings calculator, disclosure and privacy pages, metadata, sitemap and robots.

## Limitations

Curated images are editorial inspiration, not merchant items. Budget labels are examples, not validated prices. There are no real promo codes or commissioned referral links configured yet. No database, account, back-office CRM, live product feed, analytics, email notifications or AI service is included in this first version.

Before launch verify affiliate terms, image licensing, disclosure, actual offers, domain and configuration.
